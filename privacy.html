Privacy Policy

Last updated: November 23, 2026

Purpose

Personal Drive Connector is a private, non-commercial application that uses the Google Drive API through Rclone to manage the owner's Google Drive files.

Information accessed

The application may access Google Drive files, folders, metadata, and account authorization information according to the permissions granted by the account owner.

Use and storage

Google Drive information is used only for personal file access, transfer, management, and synchronization.

Rclone may store OAuth credentials and cached file data locally on the owner's device. File content is transferred between Google Drive and destinations configured by the owner.

Data sharing

The application does not sell or use Google user data for advertising. It does not intentionally disclose data to unrelated third parties. Data may be transferred to services explicitly configured by the owner.

Data control

The owner can delete local credentials and cached data or revoke access through Google Account security settings. Data stored in connected services must be managed separately.
